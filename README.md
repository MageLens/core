# MageLens Core

**Status: Planned**

MageLens Core is intended to contain shared, platform-independent components for code coverage across MageLens projects.

The planned work includes extracting common coverage collection, test-run orchestration, reporting, and related infrastructure from [MageLens](https://github.com/MageLens/MageLens), so it can be reused by integrations for different commerce platforms. Platform-specific behavior will remain in the corresponding integrations.

The project is in the planning stage. The shared components have not yet been extracted, and no package or release is available.

For the broader proposal, see [Symfony Commerce Platform Support](https://github.com/MageLens/MageLens/wiki/Symfony-Commerce-Platform-Support).
